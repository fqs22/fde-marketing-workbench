# FDE工作台 — 澳洲移民自动化营销系统

基于FDE（Funnel-Drip-Engagement）自动化营销模型搭建的实际可运行的运营工作台。

## 项目背景

面试深圳心合量子文化发展有限公司「AI产品经理搭建师 FDE」岗位的实战作品，基于个人澳洲移民赛道小红书运营+企业微信私域转化的真实经历开发。

## 核心功能（8大模块）

### 1. 数据看板（Dashboard）
- 实时统计：在跟客户数、签约数、待回数、话术库总量
- 7层漏斗可视化总览
- 今日Drip任务自动生成
- 客户分层分布图（A/B/C/D）

### 2. 漏斗模型（Funnel）
- 7层转化漏斗：曝光→互动→私信→加微→评估→深度咨询→签约
- 各层转化率 vs 目标值达标分析
- 漏斗数据可编辑

### 3. 滴灌SOP（Drip）
- 30天四阶段标准化培育SOP
  - 信任建立期（Day 1-7）
  - 意向推进期（Day 8-14）
  - 深度咨询期（Day 15-20）
  - 长线跟进期（Day 21-30）
- 客户滴灌进度追踪
- 每日动作自动匹配

### 4. 客户管理（Engagement）
- 完整CRUD操作
- 按阶段/分层/关键词筛选
- 一键推进转化阶段
- A/B/C/D分层标签体系

### 5. 话术库（Engagement）
- 4类话术：破冰(5) + 异议处理(6) + 促单(5) + FAQ(5)
- 关键词搜索 + 类型筛选
- 一键复制使用
- 支持新增话术

### 6. 笔记分析（Content）
- 笔记数据回溯：曝光/点赞/收藏/评论/私信/加微率
- 竞品分析：4个对标账号 vs 自己
- 智能改善建议：基于数据自动生成优化方向
- 支持CSV导入（小红书创作者后台导出）

### 7. 对接配置（Integration）
- 企业微信API对接指南（5步部署 + 配置表单）
- 小红书半自动CSV导入方案
- 自动同步频率设置

### 8. 系统设置
- 账号信息配置
- 漏斗目标值配置
- 数据导出/重置

## 技术栈

- 纯前端HTML/CSS/JavaScript（零依赖）
- 数据存储：浏览器localStorage
- 响应式设计：支持桌面/平板/移动端

## 使用方法

直接用浏览器打开 `FDE工作台_澳洲移民自动化营销系统.html` 即可使用，无需安装任何环境。
